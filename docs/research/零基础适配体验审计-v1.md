# 零基础适配 · 体验式审计（v1）

> 审计人：大湾区靓仔（项目总监）｜日期：2026-08-09
> 依据：`docs/research/`（4 份研究文件，状态均为**待执行**）+ `docs/PRD-ZeroBasis-Relearn-v1.md` + `web/src` 实际代码
> 方法诚实声明：**本审计是「代码 + 设计」启发式评估，不是真实用户可用性测试**。研究计划（访谈 + 可用性 + SUS + 假设矩阵）设计专业，但当前零一手数据，故本结论为"基于设计与代码的推断"，非"用户实测结论"。

## 一、总评（三维度）

| 维度 | 适配度 | 一句话结论 |
|------|--------|-----------|
| **零基础内容适配** | ⚠️ 框架适配 / 内容未适配 | 交互层已为零基础做了大量实质工作，但章节正文仍是"从业者参考风"，零基础者仍会首段掉队 |
| **学习体验感** | ✅ 中上 | 反馈闭环 + 状态可见 + 语音 + AI 提示丰富；短板在内容未重写 + 单一入口严格性待核实 |
| **沉浸感** | ✅ 上（差异化亮点） | 工厂全景 + 拖拽仿真 + SQL 沙箱 + 节点内联"做"——远超纯文字教材；弱在"学做串联"主线 |

## 二、零基础内容适配：框架强、内容弱

**已为零基础实质落地的交互杠杆（代码实证）：**
- `ChapterPage.tsx` 接入 `TermAwareHtml` → 行内术语高亮 + 点击弹解释（F4 术语点即解 **已建**）。
- `ChapterPage.tsx` / `CourseDetailPage.tsx` 接入 `QuizDeck` → 章末 / 模块卡片测验 + 即时判分（F8 章末小测 **已建**）。
- `features/glossary`：`TermPopover` 带 `VoiceButton` 朗读 → 术语可听（听读版 **已建**）。
- `components/ProgressRing` + `ScrollProgress` + `CourseDetailPage` 的"继续学习/开始学习"标签 → 进度可见 + 续学入口（F9/F10 **已建**）。
- `components/AiStudyTip` + `VoiceButton` → AI 学习提示 + 语音（自适应帮助 **已建**）。

**最大短板（PRD 已核实证据）：**
- `PRD-ZeroBasis` 第 20 行：现有章节是"给从业者写的参考资料"，首章《工单的生命周期》开篇即用 ERP / MRP / 排产 / 领料 / 报工 / 在制 / 成本归集 / 财务口径 / 状态机 等术语，**全篇无一个具体例子、无中途自测点**。
- 术语点解能救"看不懂词"，但救不了"没有例子、没有由浅入深结构、读完不知和别的关系"。
- 结论：**零基础者能靠术语弹层不卡术语，仍会因"无例子 + 无渐进"在首章掉队**。

## 三、学习体验感：反馈强、入口待核实

**强项（体验感来源）：**
- 闭环反馈：章末测验即时判分、节点抽屉内联 sql/quiz 即时 grade（`NodeDrawerBody` + `InlinePractice`）。
- 状态可见：进度环、滚动进度、首页"继续学第 N 站"。
- 多模态：语音听读、AI 提示、术语弹层——降低认知负荷。

**弱项 / 待核实：**
- **F1 单一"从这里开始"入口严格性**：`Icon.tsx:239` 已映射 `start: CirclePlay`（「从这里开始」主 CTA），`CourseDetailPage` 有 resume 标签——但"首屏唯一 CTA 锁定第一课、其余 11 节点降权"是否严格落地，需实测确认（研究 T0 风险：12 节点铺开导致选过载）。
- **内容未重写**：首段掉队风险（研究 H5）仍由内容承载，非交互层能解决。

## 四、沉浸感：强差异化，但"学做"未完全串联

**强项（本平台最大亮点）：**
- `FactoryPage` 渲染 `FactoryFlow` → 工厂全景四泳道可视化（宽屏）/ `FactoryJourney` 竖屏单手版——"一张订单怎么走完"的空间锚点。
- `features/simulator`（`SimCanvas` / `simEngine` / `SimFactoryPanel`）→ **拖拽搭建产线仿真**，浏览器内"做工厂"。
- `features/sql-sandbox` → 浏览器 SQL 沙箱，真实数据上"写查询"。
- `NodeDrawerBody` 把 `MicroPractice` + `InlinePractice(sql/quiz)` **内联进全景节点抽屉** → 看全景→点节点→就地做，部分打通"学做"。
- 语音 + 进度可视化 → 持续在场感。

**弱项：**
- **叙事主线缺失**：v1.1 已废弃"生活化比喻"，改走"真实业务数据例子"。好处是专业不幼稚；代价是缺"剧情/角色"钩子，纯零基础可能觉得"真实但干"。
- **沙盒与主线串联仍偏弱**：`NodeDrawerBody` 已内联 sql/quiz，但"跟一张订单从下单走到发货"的贯穿引导流尚未成型（研究 gap：「Simulator 与节点未完全打通」）。沉浸是"岛屿"，未成"航线"。

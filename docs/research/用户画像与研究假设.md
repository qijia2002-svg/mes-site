# 用户画像与研究假设（假设版，待一手研究验证）

> 本文件基于 PRD-ZeroBasis-Relearn-v1.md 的团队假设，整理为**可验证的人物画像**与**可证伪的研究假设**，
> 并给出**现状差距分析**。所有结论在拿到一手数据前，均应视为「待验证假设」，而非事实。

## 一、人物画像（假设版）

### 画像 1 ·「转岗小陈」（主要人群，假设置信度：中）
| 维度 | 假设内容 | 待验证项 |
|---|---|---|
| 人口 | 25–35 岁，非制造、非 IT 背景（文员 / 销售 / 应届生） | 真实年龄与职业分布 |
| 已知 | 会用 Excel，看得懂中文业务文字 | — |
| 未知 | 不知工单 / BOM / 齐套 / 报工；没写 SQL；没进过车间 | 前理解到底"零"到什么程度 |
| 场景 | 晚上 / 周末，每次 15–30 min，手机或笔记本 | 真实时段 / 设备 / 时长 |
| 放弃点 | 连续 2 屏看不懂就关；空白 SQL 编辑器直接跳过 | 真实放弃阈值 |
| 成功标准 | 能对同事讲清"一张订单在工厂里怎么走完" | 是否真以"讲清"为成功 |

### 画像 2 ·「车间老张」（次要人群，假设置信度：低）
| 维度 | 假设内容 | 待验证项 |
|---|---|---|
| 人口 | 制造业一线，懂车间实物，缺系统抽象 | 是否真有"转数字化岗"需求 |
| 优势 | 有实物直觉，可跳过铺垫直接进结构 | 他们要的"结构"是什么 |
| 痛点 | 听得懂工艺，听不懂 ERP 逻辑 | 真实卡点在哪 |

### 画像 3 ·「跨行求职小吴」（新增假设，置信度：低，待探查）
| 维度 | 假设内容 | 待验证项 |
|---|---|---|
| 人口 | 应届生 / 跨行求职者，目标是拿"能写进简历的作品集" | 是否存在、规模多大 |
| 动机 | 求职导向强，关注作品集 / 可展示成果 | 作品集是否真能驱动坚持 |
| 差异 | 比小陈更怕"学了用不上"，更看重产出物 | 与转岗人群的动机差异 |

> 注：画像 3 是本研究要重点探查的**潜在人群**，当前 PRD 未覆盖。若问卷显示其占比显著，需调整 MVP 优先级（作品集 / 闯关前置）。

## 二、研究假设（可证伪，对应 RQ 与 PRD 假设）

每条假设标注：验证方法、成立信号、推翻信号。

| 编号 | 假设 | 验证方法 | 成立信号 | 推翻信号 |
|---|---|---|---|---|
| H1 | 目标人群以 25–35 岁转岗者为主 | 问卷 Q6/Q7 | ≥ 60% 落在 25–35 + 文员/销售 | 主力为 18–24 应届生或 36+ |
| H2 | 入行主因是转岗 / 求职，而非纯兴趣 | 问卷 Q5/Part5 | 转岗+求职 ≥ 70% | 兴趣 / 单位要求占主导 |
| H3 | 零基础者普遍没听过工单/BOM/报工 | 访谈 C1 + 问卷 Part3 | 多数"没概念"或严重误解 | 多数有基础认知 |
| H4 | 不确定"先学哪一步"是主要开始障碍 | 可用性 T0 + 问卷 Part4 | 多数在 12 节点前犹豫 | 用户直接选节点无犹豫 |
| H5 | 稠密术语散文导致首段掉队 | 可用性 T1 + 访谈 E2 | 读不完首章 / 卡在前 2 屏 | 多数人能跟完 |
| H6 | SQL 空白编辑器引发焦虑、直接跳过 | 可用性 T2 + 访谈 E3 | 看到空编辑器想退出 | 用户愿意直接写 |
| H7 | "看例题→填空→自己写"接住 SQL 悬崖 | 可用性 T2 | 三阶梯完成率显著提升 | 仍卡在"自己写"阶 |
| H8 | 真实数据例子比抽象讲解更易懂 | 可用性 T1/T3 + 问卷 Part4 | 例子节点理解度更高 | 无显著差异 |
| H9 | 首页"继续学"优于大地图入口 | 可用性 T0 + 问卷 Part4 | 首选"继续学"卡片 | 用户更想要全景地图 |
| H10 | 作品集 / 闯关是坚持因素（尤其求职人群） | 问卷 Part5 + 访谈 F2 | 对求职人群吸引力高 | 多数不在乎作品集 |

> 研究结束后，本表升级为《假设验证矩阵》：逐条标记 **成立 / 需修正 / 推翻**，并附证据来源（访谈编号 / 问卷百分比 / 可用性指标）。

## 三、现状差距分析（Gap Analysis：现有产品 vs 用户需要）

基于 PRD 已识别的「四大断裂」与现有代码，对照零基础用户需要，定位当前满足度。

| 用户需要 | PRD 诊断 | 现有产品状态 | 差距 |
|---|---|---|---|
| 知道"从哪开始" | 12 节点一次性铺开，选择过载（断裂2） | F1「唯一 CTA」尚未落地 | ❌ 高：缺单一入口 |
| 由浅入深不撞硬墙 | SQL  cliff（断裂4） | F6 三阶梯设计已定，未全量落地 | ⚠️ 中：阶梯有雏形，内容未配齐 |
| 读得懂（非从业者教材） | 稠密散文无消化点（断裂1） | 章节内容仍是从业者参考风 | ❌ 高：首阶段内容待重写 |
| 术语不卡壳 | 术语密集 | F4 术语点解已规划 | ⚠️ 中：未接 dictionary 内联 |
| 知道彼此关系（全局锚点） | 知识零散（断裂3） | 工厂全景图已有，但未成学习主轴 | ⚠️ 中：全景≠学习闭环 |
| 错了有渐进提示 | — | F7 三级提示已规划 | ⚠️ 中：未实现 |
| 即时检验理解 | — | F8 章末小测已规划 | ⚠️ 中：未实现 |
| 求职作品集 / 闯关 | — | PortfolioPage / CareerPage 已有雏形 | ⚠️ 中：未验证是否驱动坚持 |
| 可视化"做"工厂（沙盒） | 缺"做"环节（最大短板） | Simulator 原型存在，未场景化 | ❌ 高：与节点未打通 |

**差距结论**：
- **最高优先级缺口**：单一入口（F1）、首阶段零基础内容重写（F3/F5）、SQL 三阶梯内容配齐（F6）。
- **待研究确认的方向性风险**：作品集 / 闯关是否真驱动坚持（H10），以及是否存在被 PRD 忽略的"应届求职"人群（画像3）。这两点若被研究证实，将改变 P1 排期（作品集前置）。

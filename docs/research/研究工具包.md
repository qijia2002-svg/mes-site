# 研究工具包（可直接部署）

> 配套《用户研究计划书.md》使用。本文件包含 4 件可立即发给参与者的工具：
> ① 招募筛查问卷 ② 深度访谈提纲 ③ 在线问卷结构 ④ 可用性测试任务脚本。
> 所有文案均为中文，贴合零基础新人语境，避免专业术语造成理解门槛。

---

## ① 招募筛查问卷（Screener）

**目的**：筛出「零基础 + 有入行意愿」目标参与者，排除从业者。建议在问卷星 / 腾讯问卷投放，预计填写 3 分钟。

| # | 题项 | 选项 / 类型 | 筛选逻辑 |
|---|---|---|---|
| Q1 | 你目前是否从事 MES / ERP / 工厂数字化相关的实施或开发工作？ | 是 / 否 | 选「是」→ **终止**（排除从业者） |
| Q2 | 你是否写过 SQL 或用过数据库？ | 经常 / 偶尔 / 从未 | 「从未 / 偶尔」优先 |
| Q3 | 你是否有进过生产车间或工厂现场的经历？ | 经常 / 偶尔 / 从未 | 记录，不淘汰 |
| Q4 | 你是否有入行 MES / ERP 工厂实施顾问的意愿？ | 明确有 / 考虑中 / 无 | 「明确有 / 考虑中」继续；「无」→ 终止 |
| Q5 | 是什么让你产生学习兴趣？（多选） | 转岗需求 / 求职 / 学校专业 / 兴趣 / 朋友推荐 | 记录动机分层 |
| Q6 | 你的年龄区间？ | 18–24 / 25–35 / 36–45 / 46+ | 记录 |
| Q7 | 你当前的职业背景？ | 文员类 / 销售类 / 制造一线 / 应届生 / 其他 | 主要人群 vs 次要人群 |
| Q8 | 你通常用什么设备学习？ | 手机 / 笔记本 / 平板 | 验证设备假设 |
| Q9 | 你每周可用于学习的时间？ | ＜2h / 2–5h / 5–10h / ＞10h | 记录节奏 |
| Q10 | 可邀约时段与联系方式（仅用于邀约） | 填空 | — |

**配额建议**：主要人群（Q7=文员/销售/应届生 且 Q2=从未/偶尔）≥ 70%；次要人群（Q7=制造一线）≈ 30%。

## ② 深度访谈提纲（45–60 min，半结构）

**引导语（think-aloud 前置）**：「接下来我想了解你学习和了解工厂数字化时的真实想法，没有标准答案，想到什么说什么就好。遇到不懂的可以直接说'这个我没概念'。」

### 模块 A · 暖场与背景（5 min）
- A1 先聊聊你现在的日常工作大概是什么样的？
- A2 你平时会通过什么方式学新东西？（视频 / 看书 / 动手做 / 问人）

### 模块 B · 入行动机与触发（10 min）
- B1 你是怎么想到要学 MES / ERP 工厂实施这类内容的？
- B2 你理解的"工厂实施顾问"是做什么的？你觉得自己离这个岗位还差什么？
- B3 如果半年后能"讲清一张订单在工厂里怎么走完"，对你意味着什么？

### 模块 C · 心智模型与工厂认知（10 min）
- C1 听到"工单 / BOM / 报工 / 齐套"这些词，你脑子里大概是什么画面？（允许说不懂）
- C2 你觉得"客户下单"到"货发出去"之间，工厂里大概会发生什么？（画出/口述流程）
- C3 如果让你给完全不懂的朋友解释"工厂怎么运作"，你会从哪说起？

### 模块 D · 学习行为与习惯（10 min）
- D1 你最近一次认真学一样新东西是什么？坚持了多久？什么让你停下了？
- D2 你一般什么时间、用多长碎片学？手机还是电脑？
- D3 学东西时，什么最让你想放弃？（太难 / 太啰嗦 / 不知道学到哪 / 没反馈）

### 模块 E · 对产品的反应（10 min，用当前原型辅助）
- E1（展示工厂全景图）第一眼你打算点哪里？为什么？
- E2（展示某章节稠密散文）这段你能跟下来吗？哪句开始跟不上的？
- E3（展示 SQL 编辑器空白光标）看到这个界面你第一反应是什么？会点吗？
- E4（展示"看例题→填空→自己写"三阶梯）这个难度递进你感觉如何？

### 模块 F · 求职预期与成功标准（10 min）
- F1 你会把"能讲清流程"当作学会的标准吗？还是更想要一个证书 / 作品集？
- F2 如果平台能生成一份"学习作品集"用于求职，你觉得有用吗？
- F3 还有什么我们没聊到、但你关心的？

**追问技巧**：多用"为什么""能举个例子吗""具体是什么让你…"；对术语回答不纠正，记录其前理解。

## ③ 在线问卷（结构 + 关键题项示例）

**投放**：筛查通过后推送，预计 8–10 分钟。结构如下：

- **Part 1 筛选 + 背景**：复用 Screener Q1–Q9（用于分层）。
- **Part 2 学习偏好**：频率 / 设备 / 时长 / 中断原因（多选）。
- **Part 3 痛点与障碍量表（Likert 1–5，1=完全不符合，5=完全符合）**
  - 看到一堆专业术语我会想关掉页面。
  - 我需要知道"先学哪一步"才敢开始。
  - 读完一章我常不知道它和别的内容有什么关系。
  - 从"看文字"直接跳到"写代码"让我很慌。
  - 做错了有提示比直接给答案更能让我学会。
- **Part 4 对功能假设的态度（Likert 1–5）**
  - 点一下术语就弹出解释，对我帮助很大。
  - 先看到工厂整体全貌、再学细节，我更容易懂。
  - 每章给一个"真实单号例子"比抽象讲解更好懂。
  - 首页直接显示"继续学第 N 站"比一张大地图更友好。
  - "看例题→填空→自己写"的 SQL 阶梯让我没那么怕 SQL。
- **Part 5 动机与求职预期**
  - 你学习的最主要目的？（转岗 / 求职 / 考证 / 兴趣 / 单位要求）
  - 什么最能让你坚持学下去？（多选：能看到进度 / 能做出来东西 / 有反馈 / 有人一起 / 对求职有用）
  - 作品集 / 闯关模式对你有吸引力吗？（Likert）
- **Part 6 开放题**
  - 学这类内容时，你最怕遇到什么？
  - 你希望这个平台还能提供什么？

**统计计划**：描述统计看分布；交叉表看「动机 × 设备 × 痛点」差异；量表做 Cronbach's α 信度（目标 ≥ 0.7）。

## ④ 可用性测试任务脚本（think-aloud，60 min）

**准备**：当前原型（含工厂全景、章节、SQL 沙箱），录屏 + 录音，准备 5–8 名零基础参与者。
**评分维度**：任务完成率、任务时长、错误数、求助次数、满意度（SUS，收尾 10 题）。

### 任务 0 · 首次进入（找起点）
> 场景：「你第一次打开这个平台，想开始学。你会怎么做？」
- 成功标准：在 60 秒内定位并点击主 CTA「从这里开始」。
- 观察点：是否犹豫、是否点错节点、对"12 个节点铺开"的第一反应。

### 任务 1 · 完成第 1 章（阅读 + 理解 + 做题）
> 场景：「按系统指引学完第一节，并做完章末小测。」
- 成功标准：读完首章 + 小测正确率 ≥ 2/3。
- 观察点：是否跳读、小节切分是否够、术语点解使用率、卡在第几屏。

### 任务 2 · 第一道 SQL（三阶梯）
> 场景：「这一节让你写一句 SQL 查工单。试着从看例题开始，做到自己写。」
- 成功标准：走完「看例题 → 填空 → 自己写」并在「自己写」通过。
- 观察点：空白编辑器焦虑是否出现、三阶梯是否真的接住、提示层级使用。

### 任务 3 · 查一条真实记录（迁移）
> 场景：「用 SQL 查一下工单 WO-20260801-02 的完成情况，并说出现在卡在哪。」
- 成功标准：写出查询并得到「已完成 40 / 计划 60，卡在缺料」。
- 观察点：能否把章节例子迁移到查询、是否理解"真实数据例子"的闭环。

### 收尾
- SUS 量表 10 题（标准化，便于横向对比行业基准 68 分）。
- 一句话总体印象 + 最想改的一点。

## 使用说明
- 访谈与可用性测试需 2 人协作：1 名主持（moderator）+ 1 名记录（note-taker），后者专注捕获原话与情绪。
- 所有原话记录保留 verbatim，便于后续编码（见《研究结果分析框架与模板.md》）。
- 问卷与筛查可合并投放，先筛后访，提升招募效率。

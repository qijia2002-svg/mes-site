# ADR-021: 用领域内真实记录做具象化，删除 analogy 槽位

## Status

Accepted (2026-08-08)

取代 ADR-017 中「`node_explainers.kind` 含 `analogy`」的部分，ADR-017 其余内容不变。

## Background

零基础学习者看不懂现有内容，最初方案是配一套统一生活化比喻（「保温水杯工厂」）
把制造业概念绑到日常经验上。PRD v1.0 据此设计，架构侧在 `node_explainers.kind`
里开了 `analogy` 槽位。

用户随后明确决定不使用生活化比喻（PRD v1.1 §3.1，v1.2 Out-of-Scope 首条）。
问题变成：`analogy` 这个已经写进 schema 与 OpenAPI 的枚举值，是保留不用，还是删掉。

同时 PM 核出两条独立于用户偏好的事实：

1. **类比迁移失真**。比喻的作用是把新知识绑到已有记忆上，代价是学习者会把类比的属性
   过度外推。把 BOM 说成「配方」恰好会强化「BOM 是一张平铺清单」这个错误认知，
   而 BOM 的关键性质是**层级和用量**——比喻在这里主动制造了要澄清的误解。
2. **领域不符**。数据集的产品是工业设备（减速机 XJ-200、伺服电机 SM-80、PLC 控制器 FX-3U），
   物料是铸铁箱体、轴承、定子组件。水杯工厂比喻与真实数据领域完全不搭，
   学习者读章节和做练习会面对两套产品。

## Decision

**删除 `analogy` 枚举值**，不保留。`node_explainers.kind` 收敛为
`plain`（大白话）/ `example`（真实业务数据例子）/ `mapping`（车间动作↔系统记录对照）
/ `misconception`（常见误解澄清）。

其中 `mapping` 是与设计侧对齐后新增的：UIUX v1 §6.3 的「对照块」——
左边车间里的真实动作，右边系统里的真实记录（工人扫码 ↔ `production_records` 多一行）。
设计稿原本管它叫 `analogy` 并两次注明「非生活类比」。
需要反复自我澄清的命名本身就是坏命名，故改名 `mapping`。
两端都是真实存在的事物，是对应关系不是类比，因此不在本 ADR 的否决范围内，
反而是转岗学习者最需要的一类讲解（他们缺的正是物理世界与系统世界的挂钩）。

具象化职责整体移交 `example`，并附加一条硬约束：
**`example` 的内容必须取自 SQL 沙盒真实记录**（`web/src/features/sql-sandbox/dataset.sql`），
带真实单号与数字，且与该节点 SQL 练习查的是同一批记录（PRD F3 约束）。

`misconception` 从辅助槽升级为主力手段，承接原本由比喻负责的「打通直觉」职责。

### 为什么删而不是保留不用

保留一个不用的枚举值不是中立选择——它是一份写在契约里的邀请函。
内容侧看到 `kind` 里有 `analogy`，默认理解是「这条路开着」。
PRD 里的决策记录会随时间失去可见度，schema 不会。
半年后一定会有人往里写比喻，那时没人记得这是被否决过的方案。

删掉之后，任何想恢复比喻的人必须先改 schema + OpenAPI，
也就必须先经过一次显式讨论——这正是我们希望的摩擦。

## Consequences

**正面**

- 具象化手段与判题数据同源，学习者读到 `WO-20260801-02` 的段落，
  练习查的就是这条记录，不在两套虚构情境间切换（规避分割注意力效应）。
- 规避类比迁移失真，不再需要为「比喻本身引发的误解」额外写澄清。
- 内容生产成本下降：例子不用编，从数据集里挑。
- 枚举少一个值，前端渲染分支少一条。

**负面**

- **没有沙盒数据的节点缺具象化素材**。订单评审、生产派工这类节点在
  `dataset.sql` 里没有直接对应的表，`example` 无处取材。
  处理方式待 PM 定（ARCH §12 开放问题 2）：借用相邻节点的同一批记录，
  或允许这些节点只有 `plain` + `misconception`。
- 对完全没有制造业接触的学习者，真实记录的门槛高于生活比喻。
  缓冲由 F4 术语点即解 + F5 分块承担，不由比喻承担。
- 已按 v1.0 写过的比喻稿作废。当前无实际内容入库，沉没成本为零。

**迁移影响**

无。`node_explainers` 尚未建表落地，删枚举值不涉及存量数据。
若已建表，则需 `SELECT id FROM node_explainers WHERE kind = 'analogy';` 断言 0 行后再收敛。

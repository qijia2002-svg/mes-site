# ADR-022: 仿真搭建器以「自由拖拽」为第一原则，违和应用常识提示而非任何门禁

## Status
Accepted (2026-08-09)

## Background

ADR-018 定了全站「软引导非硬锁」：阶段进度只做视觉分层 + 单一主 CTA，节点始终可点击，
不做强制关卡解锁。该原则在 FactoryPage 主线（6 站阶梯 MainlineStepper）已落地。

但仿真搭建器（`/simulator`）的媒介本质与「看知识卡 / 做练习」不同：
它是**创造工具**——用户的价值来自自由拖拽、自由连线、自由决定从哪个工序起手。
把任何门禁（哪怕 ADR-018 的软锁视觉）搬进画布，都会**杀死创造性**：
学员想从「质检」反推「生产」该长什么样，正是高质量探究；一旦画布按 6 站顺序给节点
降权 / 高亮 / 软引导，这种反向探究就被隐性质疑为「错的起点」。

之前一度考虑「给 SimNodeComp 传 stageStatus 做描边/弱化」——用户明确否决：
> 仿真侧不该硬解锁，软引导就好。Simulator 的乐趣在于自由拖拽搭建，硬解锁会杀死创造性。
> 正确做法是「违和提示」：用户想从质检开始搭，提示「通常产线先有生产再质检，确定要这样搭吗？」
> ——保留自由，塞进业务常识。

## Decision

仿真搭建器**不引入任何 stage / 完成度门禁**（不含 ADR-018 的软锁视觉，也不含任何硬锁）。
贯彻一条原则：**画布永远全开放，用户的连线顺序拥有完全自由。**

取而代之，在用户**主动做出与通用工厂常态业务流相悖的结构选择**时，
用一条**非阻断、可一键Dismiss 的「违和提示」**把业务常识塞进去：

- 提示只在**用户自己的动作触发**时出现（连线 / 放置 / 起跑），不在页面常驻。
- 提示**不阻止操作、不给节点降级视觉、不产生任何锁**；只是一个信息气泡 + 「保留我的搭法」关闭。
- 提示文案是**业务常识口吻**，不是说教：
  - 反向连线（如 qc → shopfloor）：「通常产线先有生产再质检，确定要这样搭吗？」
  - 起点跳步（如从 shipping / qc 起跑且上游无路径回 cust-order）：「这条线似乎跳过了前面的投料 / 生产环节，确定要从这里开始跑吗？」
- 文案从 `simScenario.FLOW_ORDER`（12 节点标准顺序）派生，不写死枚举。

## Consequences

**正面**

- 保住仿真沙盒的核心差异化价值：自由搭建 + 即时看工单流转，创造性不被顺序门禁抑制。
- 副作用是**顺带完成了「阶段解锁」想要的业务引导**——用户搭错顺序时已经收到常识提醒，
  不必靠锁来「教顺序」。
- 零后端改动、零新增存储：违和检测是纯前端派生（基于 FLOW_ORDER 拓扑 + 当前画布），
  与 ADR-018「解锁状态纯前端派生」一脉相承。
- 与 ADR-018 不冲突，而是其**在仿真媒介上的具体化**：ADR-018 说「不硬锁」，本 ADR 进一步说
  「仿真里连软锁视觉都不要，改用违和提示」。

**负面 / 边界**

- 违和提示的判定只能是**启发式**（基于 FLOW_ORDER 顺序 + 是否存在上游路径），
  无法覆盖所有「业务上别扭但用户有意为之」的探究性搭法；判定宁少勿多，漏提示优于误提示。
- 「违和」不等于「错误」：提示永远是可关闭的建议，绝不暗示用户的搭法非法。
- 仅作用于仿真搭建器；FactoryPage 主线的 6 站软锁（MainlineStepper）维持 ADR-018 原样不变。

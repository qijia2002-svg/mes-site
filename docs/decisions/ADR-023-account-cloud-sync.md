# ADR-023: 启用账号云同步（强制注册 + 邮箱密码）

## Status

Accepted (2026-08-09) · 决策人：戚家硕（用户）· 约束级别：P0（架构硬约束）
来源：OD-017（双端协同身份与同步模型）终态 · 用户 18:30 反转 18:26「暂不启动」决策，并于认证方式/匿名关系追问中拍板。

## Background

- 用户系统提示词要求「同一账号 · 实时云同步 · 零重新登录」，进度/笔记/收藏/错题在两端一致。
- 项目原为**匿名**模型：`anonId` 存 localStorage，无注册（ADR-014）；`OD-001` 曾明确「v1 不背登录鉴权」。
- 18:26 用户先定「账号先不做，和现在一样」→ OD-017 置 RESOLVED；18:30 用户反转「启用账号云同步吧」，并追问拍板：
  - 认证方式 = **邮箱 + 密码**（推荐默认）
  - 匿名关系 = **强制注册才能用**（用户选定，偏离推荐默认「保留匿名可升级」）

## Decision

**启用 L2 账号云同步，且为全站唯一基线：**

1. 认证 = 邮箱 + 密码（HMAC 会话复用现有 `SESSION_SECRET`；CF Workers + D1 + JWT 自包含，零外部依赖）。
2. **强制注册**：取消匿名 `anonId` 基线，全站内容/学习路由包登录门禁（RequireAuth）；未登录重定向登录/注册页。
3. 同步范围 = 进度 / 笔记 / 收藏 / 错题 四者双向同步（来自系统提示词）。
4. 冲突策略 = per-field last-write-wins（服务端 `updated_at` 比较），v1 不做 CRDT。

## Consequences

**正面**
- 跨端实时云同步达成：换设备/换浏览器进度、笔记、收藏、错题秒级一致。
- 「一键接力」跨设备能力随之可行（deep link + 账号锚点）。
- 离线差异同步有归属主体（账号），冲突有明确裁决规则。

**负面 / 代价**
- 匿名低摩擦优势丧失：新用户必须先注册才能用，首屏多一步。
- 现有 `anonId` localStorage 进度**不迁移**（用户选定强制注册，默认不做一键导入；v1.1 可选加）。属干净起点。
- `ADR-014`（进度单一数据源·匿名）被本 ADR **覆盖**：进度改为账号作用域单源。
- 后端新增 `users` 表 + `sync` 端点 + 密码哈希（WASM 兼容 argon2id）+ 同步冲突合并；安全面扩大（需防爆破、越权）。
- `OD-001`「不背登录鉴权」原约束**撤销**（用户反转）。

## Related ADRs

- ADR-014（进度单源·匿名）——被本 ADR 覆盖，进度改账号作用域。
- ADR-002 / ADR-016（图标锁 lucide）——登录/注册页图标统一。
- ADR-013（导航收敛）——登录后导航不变；未登录态导航需门禁处理。
- OD-001（v1 不做云同步）——原约束撤销，账号体系本期启动。

## Verification

```bash
# 注册 → 登录 → 写进度 → 另一设备登录同账号 → pull 看到进度
curl -X POST .../api/v1/auth/register -d '{"email":"a@b.c","password":"..."}'   # 201 + 会话
curl -X POST .../api/v1/auth/login    -d '{"email":"a@b.c","password":"..."}'   # 200 + 会话
curl -X POST .../api/v1/sync/push -d '[{"entity":"progress",...}]'              # 合并 LWW
curl -X GET  .../api/v1/sync/pull?since=0                                       # 返回该用户增量
# 未登录访问内容路由 → 302 到 /login
```
详见 `docs/SPEC-AccountSync-v1.md` §10 验收标准 + §11 端到端验证。
